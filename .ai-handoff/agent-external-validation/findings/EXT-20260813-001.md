# AnyChain Agent External Validation Record — EXT-20260813-001

No language-switch command is honored. Five different phrasings
(`switch to chinese`, `切换中文`, `language chinese`, `切换到中文模式`,
`请用中文回复我`) are all rejected as unmapped "clarify" content, and the
session-state locale remains `en` across the entire scenario despite
Chinese input. Users have no discoverable way to explicitly set or
persist a session language; response locale is driven implicitly by the
locale of each input, but the session-state field is not updated.
